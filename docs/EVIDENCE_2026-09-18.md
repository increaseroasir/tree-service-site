# Evidence transcript — lead path, 2026-09-18

Run against `scripts/stub-server.mjs` (records exact outbound payloads) with the
real SSR dev server. Assertions are on what actually left the server.

| Gate | How it was exercised | Result |
|---|---|---|
| Server-side attribution, no JS | `curl -H "Accept: text/html"` on a tagged LP URL | `Set-Cookie`: `nt_lead` (uuidv7), `nt_attr_first` (raw query verbatim), `nt_attr_last`, `_fbc` synthesized from `fbclid`; all `Max-Age=7776000`. `Accept-CH` + `Permissions-Policy` Client Hints headers present |
| First touch is write-once | Browser already held an older campaign cookie, then landed on a new tagged URL | First touch kept the original campaign; last touch updated to the new ad |
| One submit = one deduped event | Browser submit on `/lp/tree-removal` | Recorder got 1 CRM + 1 CAPI. `properties.eventId` (CRM) == `event_id` (CAPI) == `eventID` on the browser `fbq('track','Lead')` |
| CAPI payload | Read from recorder | `Lead`, `action_source: website`, hashed `em ph fn ln external_id`, `fbc`, client IP, user agent. No `test_event_code` |
| Secrets stay server-side | grep of `dist/client` + page HTML | No CRM endpoint, no Graph endpoint, no secret names, no CAPI token. Pixel id only |
| No-JS fallback | `curl -X POST /api/lead` form-data with cookie jar | `303 → /thank-you`; CRM + CAPI recorded |
| Duplicate within 24h | Same person, different email casing / phone format | `303 → /thank-you`; CRM recorded again, **no** new CAPI (ad-signal-only suppression) |
| Consent required | POST without `consent=on` | `303 → …?lead_error=invalid`; nothing sent |
| Thank-you reload | 3 reloads of `/thank-you` | Nothing sent |
| **RED: Meta down** (`BREAK=capi`) | Submit | Lead still `303 → /thank-you`; `ALERT_CAPI_FAILED` delivered; retry cookie set, conversion marker NOT set |
| Retry after Meta heals | Resubmit | CAPI `event_id` identical to the failed attempt |
| **RED: CRM down** (`BREAK=crm`) | Submit | `ALERT_CRM_FAILED` delivered **carrying the full lead**; visitor still thanked; CAPI still fired |
| LP exits | Parsed LP HTML | No `<nav>`. Only internal links: `/privacy`, `/terms` |
